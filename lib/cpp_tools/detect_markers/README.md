# Detect Markers

This is a program to perform a live demo of the ArUco detection and pose estimation. A wireframe of a calibration plate is rendered on top of the ArUco marker for visualization purposes. 

## Build Instructions

```
mkdir build
cd build
cmake ..
```

## Run Instructions
The binary takes the following arguments:
- 1
- 2
- 3
```
./build/out -1 -2 -3
```
