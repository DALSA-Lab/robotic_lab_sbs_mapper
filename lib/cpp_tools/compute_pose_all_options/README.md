# Compute Pose (all options)

Program to compute the 6DOF pose of ArUco markers, using all possible options. One CSV file is generated for each marker-option combination. Useful for comparing the effect of different detection options.

## Build Instructions

```
mkdir build
cd build
cmake ..
```

## Run Instructions
The binary takes the following arguments:
- 1
- 2
- 3
```
./build/out -1 -2 -3
```
