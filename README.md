# Robotic Lab SBS/SLAS Mapper
Welcome to the DALSA Robotic Lab SBS/SLAS Mapper Python toolkit. That's quite a mouthful, thus the python package has been dubbed *MapIt* - a play on the popular [ROS2 MoveIt](https://moveit.ai/) package.

## Documentation, guides and demos
The documentation can be found in the [`docs/`](/docs) folder, as well as online at [https://dalsa-lab.github.io/robotic_lab_sbs_mapper/](https://dalsa-lab.github.io/robotic_lab_sbs_mapper/).

The documentation includes guides on setup, usage, examples and demos, and source code docs.


## Directory Structure
```bash
.
├── build
│   └── html
├── docs
│   ├── architecture
│   ├── code
│   ├── doxygen
│   ├── integration
│   └── usage
└── lib
    ├── cpp_tools
    └── py_pkg
```
[`build/`](build/) contains the HTML build of the documentation.

[`docs/`](docs/) contains the guides and examples from which the documentation is built.

[`lib/`](lib/) contains the python package ([`py_pkg`](lib/py_pkg/)) and the C++ tools ([`cpp_tools`](lib/cpp_tools/)).
